A make.fun entry for the "Funniest Lost Sock Status Update" bounty:
https://make.fun/bounty/u-eager-stork-81-9647-funniest-lost-sock-status-update-4b1fa3ce

`main.py` (Python stdlib only) writes one status update, in the voice of a
lost sock, to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Status update: I've moved into the vacuum cleaner. The dust bunnies made
> me mayor. Tell my partner I'm thriving.

Run it with:

```sh
python3 main.py
```
